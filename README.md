# Bridgelabz Training Java Programming

A comprehensive Java learning repository covering Core Programming, Object-Oriented Programming, Data Structures & Algorithms, Advanced Java, and Design Modelling concepts.

---

## Overview

This repository represents my Java Development learning journey through the BridgeLabz Training Program.

The repository is organized into separate branches, each focusing on a specific domain of Java development. The objective is to build a strong foundation in programming, problem-solving, software design, and application development using Java.

## How to Run

Compile a Java file:

```bash
javac FileName.java
```

Run the program:

```bash
java FileName
```

Example:

```bash
javac Main.java
java Main
```
